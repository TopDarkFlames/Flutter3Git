# Listas, ListView e Cards

Aplicação Flutter baseada no material de Material 2 sobre listas e conteúdo
dinâmico. O aplicativo reúne os exemplos do material e os cinco exercícios de
fixação em uma tela inicial:

1. Lista rolável de disciplinas com `ListView`.
2. Cursos gerados com `List<String>` e `ListView.builder`.
3. Cursos apresentados com `Card` e `ListTile`.
4. Produtos representados por uma classe `Produto`.
5. Cadastro dinâmico com adicionar, limpar e remover.

## Exercícios de fixação

1. Lista de oito linguagens com `ListView.builder`.
2. Catálogo de livros usando a classe `Livro` e `Card`.
3. Lista de alunos usando a classe `Aluno` com nome e nota.
4. Cadastro de tarefas com inclusão e remoção por `IconButton`.
5. Estoque simples com nome, preço, quantidade e estado vazio.

## Executar

```bash
flutter pub get
flutter run
```

## Testar

```bash
flutter analyze
flutter test
```

O projeto não usa pacotes externos: somente o Flutter SDK e o pacote de testes
do próprio Flutter.
